# Реестр обрабатываемых данных (SuperPart) — FR-PRIV-02

Краткий перечень. Секреты и значения сюда не пишутся.

| Данные | Где | Срок / примечание |
|--------|-----|-------------------|
| Email, ФИО, роль, баланс | БД `users` | Пока учётная запись активна |
| Пароль | bcrypt hash в `users` | До смены/удаления |
| Session cookie | `sessions` / cookie HttpOnly | Idle 12 ч, absolute 7 суток |
| Заявки CRM (статус, суммы, телефон клиента) | `orders` | Пока нужна для партнёрского кабинета / аудита |
| Начисления / выплаты | `transactions`, `withdrawal_*` | Неизменяемый леджер |
| Банковская карта партнёра | `partner_bank_cards` | До удаления партнёром |
| API-ключи CRM | шифрованные поля user / `.env` | Ротация по процедуре |
| Логи webhook | `storage/logs` | Без payload с ПДн/подписями (цель SEC-02) |

Не храним: email/пароль в localStorage; cookie «запомнить email»; аналитику/fingerprint.
